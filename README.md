## 9929 到底是什么，Akile 的流量怎么走

9929 是中国联通 AS9929，圈内也叫 CUII 或 A 网，属于联通面向国际方向建设的精品承载网。它和电信的 CN2 GIA、移动的 CMIN2 是同一层级的东西：都是三家运营商里优先级较高、拥塞较少的回国通道，价格比普通 163/4837 骨干贵，路由也更干净。

拿 2024 年 3 月美国节点的实测做参照，联通方向的路径长这样：

- 北京联通：`162.219.85.85`（AS10099，洛杉矶 ChinaUnicom）→ `218.105.2.93`（AS9929，上海）→ `218.105.131.101`（AS9929，北京），落地 **150.58ms**
- 上海联通：AS9929 段出现在 `218.105.2.150`（上海），落地 **135.04ms**
- 深圳联通：AS9929 段出现在 `218.105.131.181`（广州），落地 **159.04ms**
- 成都教育网：经联通 AS9929 与 AS4837 混合，落地 193.85ms

能看出两个特征。第一，AS9929 的入口通常在上海或广州，也就是说回国第一跳不一定落在你所在的城市，之后还要走一段 AS4837 骨干才到省网。第二，同一台机器在不同城市的落差能到 24ms，广东方向的落地时间比上海长。

这就是 9929 的实际含义：它保证你从境外回国时走的是联通精品网，不保证最后一公里，也不保证端口带宽。
